# ことのは

**身元を明かす前に、価値観からつながる。**

[動くアプリ](https://kotonoha-first-connect-uchida.seira20071004.chatgpt.site) / [開発用ソース](web) / [実装と制約](web/README.md)

## 製品概要
### 背景
出会いの会話では、相手を知りたい一方で、まだ信用できるか分からない相手に大学・生活圏・本名まで伝えたくない葛藤がある。
ことのはは、個人情報を減らしながら、好きなことや希望する関係を伝えられる体験を目指す。

### 製品説明
6分野14問の選択式質問から、恋愛スタイル・ライフスタイル・コミュニケーション・理想の関係・食・将来の希望を整理する。
短い会話から性格を推測して断定せず、本人が回答と公開範囲を確認する。
公開した回答で相性を説明し、相互に関心を持った相手と会話する。

### 特長
1. **自動で一般化 → 最後に確認**：大学名や駅名、連絡先などを端末内で加工し、元の意味をできるだけ残す。ユーザーが隠す場所を探す操作は必須にしない。
2. **回答を根拠にした相性**：未回答を中間値で埋めず、6分野の一致と違いを表示する。相性スコアはマッチ確率や心理検査ではない。
3. **写真の自動マスキング案**：端末内で文字・顔の候補を検出。モデルも同一サイトから読み込み、写真を外部AIへ送らない。
4. **自分らしいチャット**：加工後の文章だけを確認してからOpenAIへ渡し、自然な言い換え・ユーモアのある言い換えを提案する。

## 共同開発をはじめる
```sh
git clone git@github.com:jphacks/ng_2608.git
cd ng_2608/web
npm ci
npm run dev:local
```
表示された `http://127.0.0.1:5173` を開く。APIキーなしでも質問回答・端末内加工・架空の相手とのデモを試せる。
AIを使う場合は、各開発者の安全なキー設定フローで `web/.env.local` を設定する。キーをGitやチャットで共有しない。

```sh
npm test
```

- 画面と会話: `web/public/demo/app.js`
- 14問の定義・6分野の相性計算: `web/public/demo/questionnaire.js`
- 質問画面・公開確認: `web/public/demo/questionnaire-ui.js`
- 文章の一般化・AI入出力検証: `web/public/demo/privacy.js`
- 写真の端末内検出: `web/public/demo/photo-detection.js`
- 写真の加工: `web/public/demo/photo.js`
- AI接続: `web/lib/ai/gateway.mjs`
- 保存・会話のアクセス制御: `web/lib/community.mjs`
- スキーマと移行: `web/db/schema.ts` / `web/drizzle/`

## 開発技術
- JavaScript、TypeScript、Vinext、Cloudflare Workers / D1 / R2
- OpenAI Responses API（加工済み文章のみ・本人確認後）
- Tesseract.js、MediaPipe Tasks Vision（端末内の文字・顔候補の検出）
- Node.jsのテストランナー、SQLiteによる権限・会話・相性のテスト

## 解決できることと制約
うっかりした情報開示を減らし、何を伝えるかを本人が選ぶ手助けをする。
完全な匿名化や相手の信頼性を保証しない。写真には見落とし・誤検出があり、最後の確認が必要。
年齢は自己申告。通報の受付記録は保存するが、専任の即時対応運用は未提供。

## 今後の展望
多様な日本語表現と写真で検出の検証を増やし、本人確認・年齢確認・通報運用を整備する。
相性の重みや質問は利用者への検証を通じて見直す。現段階の重みは仮の製品ルール。
