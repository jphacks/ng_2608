# チャット・背景変更・価値観トークの追加

## 起動

Node.js 24以降を推奨します。既存の手順をそのまま利用できます。

```sh
cd web
npm ci
npm run dev:local
```

http://127.0.0.1:5173 を開きます。ローカルデータは `.sites-runtime` 内に保存され、既存DBには `0003_conversation_insights.sql` が自動適用されます。

## 追加された操作

- **端末内AIの準備**：画面右上の接続設定から「端末内AIを準備する」を押します。WebLLM / Qwen2.5-1.5Bが初回にモデルを取得します。WebGPU対応端末と十分なメモリが必要です。読み込み中・未対応・失敗を区別し、確認ができない文章は送信しません。モデルの配信サーバーには通常のダウンロード通信が発生しますが、確認対象の文章は送りません。
- **通常送信**：ルール→端末内AIの順に確認します。変更がなければ送信。変更があれば確認・編集画面から入力欄に戻し、利用者が送信を押したときに再確認します。外部AIは呼びません。
- **文章補助**：入力欄の「ちょっとボケる」「会話を広げる」を押し、加工済み文章と目的を確認した場合だけ外部AIへ送信します。候補を端末内で再確認して入力欄に戻し、相手には自動送信しません。
- **背景変更**：写真を選ぶとMediaPipeで人物と背景を分離します。消す・戻す・10操作までの取り消し・ブラシサイズ・拡大・5種類の背景を用意しました。拡大後はプレビューの余白からスクロールできます。写真全体を確認して「この画像にする」で、平坦化したJPEGだけを保存します。複数の顔や人物分離の失敗では保存を止めます。
- **価値観トーク**：既存14問の後に、固定された3つの場面を表示します。質問はアプリ側で管理し、外部AIはリアクションと最後のまとめを返します。全回答の加工・送信確認、スキップ、脱線、未回答、実在する回答の根拠引用を扱います。結果の編集・項目ごとの公開・全項目の公開解除に対応します。
- **会話中の相性ヒント**：相手ごとに初期無効です。双方が許可すると、端末内AIが送信済みの本人の発言から希望の候補を抽出します。本人が確認・訂正した希望と引用だけを比較用に保存します。比較は休日・連絡ペース・希望が違うときの決め方の3分野です。3分野双方に情報が揃うまで数値を表示しません。各分野の選択値のJaccard一致率を均等に平均した製品上の参考値であり、心理検査や恋愛の成功率ではありません。

相性ヒントで会話を外部AIへ送信する機能はありません。本人の直近6件の発言から候補を抽出し、正規表現の組み合わせ注意は画面に読み込んだ直近100件のうち自分の発言と下書きに適用します。対象範囲は画面に明記します。相性データは本人が除外でき、同意撤回やブロックで双方の比較用データを消去します。元の会話を消す操作ではありません。

## 外部AIの設定

価値観トークと文章補助には、サーバー側の `OPENAI_API_KEY` が必要です。ローカルでは自分で `.env.local` に設定します。`OPENAI_MODEL` を省略したローカル起動では従来の `gpt-4.1-mini` を利用します。公開環境は既存の秘密変数設定を使います。キーをGitや配布物に含めないでください。

この変更にAPIキーは含まれません。外部APIの実通信には利用者側の設定が必要です。自動再送や、失敗時の原文送信は行いません。サーバーはリクエストの承認、入力形式、原文の残存候補、生成出力を検証し、Responses APIは `store:false` を指定します。これ自体は外部事業者側のすべての保存・監視を無効にする保証ではありません。

## 開発と検証

```sh
npm test
npx tsc --noEmit
npm run build
```

端末内AIのWorkerソースを変更した場合：

```sh
npm run local-ai:prepare
```

写真モデルと実行ファイルを再作成する場合：

```sh
npm run vision:prepare
```

公開する場合は、既存の移行に続けて `drizzle/0003_conversation_insights.sql` をDBへ適用してください。元サイトの公開・アクセス設定はこのローカル変更では更新していません。

## 主なファイル

- `public/demo/conversation-upgrade.js`：既存画面・登録手順との接続
- `public/demo/local-ai.js` / `worker/local-ai-worker.mjs`：端末内AI
- `public/demo/safety.js`：追加の検出と履歴の組み合わせ注意
- `public/demo/background-photo.js`：背景変更・マスク編集
- `public/demo/values.js` / `lib/ai/values-contract.mjs`：固定3問とAI出力検証
- `public/demo/insights.js` / `lib/insights.mjs`：相性の比較・同意・根拠のアクセス制御
- `tests/insights.test.mjs` / `tests/values.test.mjs`：追加した契約・権限・処理分岐の検証

## 残る制約

端末のGPU・メモリによって処理時間や対応状況が変わります。小型の端末内AIや画像モデルにも誤検出・見落としがあり、匿名性を保証しません。相性の根拠引用が存在することは検証しますが、引用の意味の解釈が正しいかは本人が確認します。外部AIの実通信と、各種実機スマートフォンでの長時間利用は、キー設定・対象実機での追加確認が必要です。
